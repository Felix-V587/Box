## 三、配置地址解析核心实现

### 3.1 核心类：ApiConfig.java

**位置**：`app/src/main/java/com/github/tvbox/osc/api/ApiConfig.java`

这是配置管理的核心类，负责加载和解析配置文件。

### 3.2 配置解析流程

```
1. HomeActivity.initData()
   ↓
2. ApiConfig.loadConfig()  [获取配置URL]
   ↓
3. 处理特殊格式
   - clan:// → clanToAddress()
   - ;pk; → 提取密钥
   ↓
4. OkGo.get(configUrl)  [网络请求]
   ↓
5. convertResponse()
   - FindResult()  [解密]
   - clanContentFix()  [Clan路径修复]
   - fixContentPath()  [相对路径修复]
   ↓
6. parseJson()  [解析JSON配置]
   - 解析站点源
   - 解析解析器
   - 解析直播源
   - 解析规则
   ↓
7. callback.success()  [回调成功]
```

### 3.3 核心函数详解

#### 3.3.1 配置加载入口：loadConfig()

**位置**：第140-235行

**功能**：
1. 从 Hawk 获取配置URL (`HawkConfig.API_URL`)

4. 异步加载配置文件

#### 3.3.3 Clan地址转换：clanToAddress()

**位置**：第848-856行

```java
String clanToAddress(String lanLink) {
    if (lanLink.startsWith("clan://localhost/")) {
        return lanLink.replace("clan://localhost/", 
               ControlManager.get().getAddress(true) + "file/");
    } else {
        String link = lanLink.substring(7);
        int end = link.indexOf('/');
        return "http://" + link.substring(0, end) + "/file/" + link.substring(end + 1);
    }
}
```

#### 3.3.4 配置内容解密：FindResult()

**位置**：第103-128行

```java
public static String FindResult(String json, String configKey) {
    String content = json;
    try {
        if (AES.isJson(content)) return content;
        
        // 处理Base64编码
        Pattern pattern = getPattern("[A-Za-z0]{8}\\*\\*");
        Matcher matcher = pattern.matcher(content);
        if (matcher.find()) {
            content = content.substring(content.indexOf(matcher.group()) + 10);
            content = new String(Base64.decode(content, Base64.DEFAULT));
        }
        
        // 处理AES加密
        if (content.startsWith("2423")) {
            // CBC模式解密
            String data = content.substring(content.indexOf("2324") + 4, content.length() - 26);
            content = new String(AES.toBytes(content)).toLowerCase();
            String key = AES.rightPadding(content.substring(content.indexOf("$#") + 2, content.indexOf("#$")), "0", 16);
            String iv = AES.rightPadding(content.substring(content.length() - 13), "0", 16);
            json = AES.CBC(data, key, iv);
        } else if (configKey != null && !AES.isJson(content)) {
            // ECB模式解密
            json = AES.ECB(content, configKey);
        } else {
            json = content;
        }
    } catch (Exception e) {
        e.printStackTrace();
    }
    return json;
}
```

#### 3.3.5 内容路径修复：fixContentPath()

**位置**：第863-873行

```java
String fixContentPath(String url, String content) {
    if (content.contains("\"./")) {
        url = url.replace("file://","clan://localhost/");
        if (!url.startsWith("http") && !url.startsWith("clan://")) {
            url = "http://" + url;
        }
        if (url.startsWith("clan://")) url = clanToAddress(url);
        content = content.replace("./", url.substring(0, url.lastIndexOf("/") + 1));
    }
    return content;
}
```

## 四、支持的配置格式

| 格式 | 标识 | 说明 |
|------|------|------|
| 普通JSON | - | 直接解析 |
| Base64编码 | `********`前缀 | Base64解码后解析 |
| AES-ECB加密 | `;pk;`分隔符 | 需提供密钥进行解密 |
| AES-CBC加密 | `2423`开头 | 内置密钥提取机制 |
| Clan本地协议 | `clan://`前缀 | 转换为本地服务器地址 |
| 相对路径 | `./`开头 | 转换为绝对路径 |

## 七、总结

TVBox 项目的配置系统设计灵活且功能完善：

1. **多格式支持**：支持普通JSON、Base64编码、AES加密等多种配置格式
2. **多协议支持**：支持HTTP、HTTPS、Clan本地协议
3. **安全机制**：内置AES-ECB和AES-CBC解密功能
4. **路径处理**：自动处理相对路径转换为绝对路径
5. **缓存机制**：支持配置缓存，提升加载速度
6. **扩展性强**：通过Spider JAR机制支持动态扩展

这种设计使得应用能够适应各种不同的配置源场景，既支持远程配置也支持本地配置，既支持明文配置也支持加密配置，为用户提供了极大的灵活性。
