# TVBox 本地服务器 API 接口分析

## 服务器信息

- **默认端口**: 9978
- **本地地址**: http://127.0.0.1:9978
- **功能**: 提供Spider执行和数据处理

## 主要API接口

### 1. 搜索接口

**接口**: `/api?do=search`

**参数**:
- `id`: 站点key
- `wd`: 搜索关键词

**示例**:
```
GET http://127.0.0.1:9978/api?do=search&id=玩偶&wd=仙逆
```

**返回格式**:
```json
{
  "list": [
    {
      "vod_id": "1",
      "vod_name": "仙逆",
      "vod_pic": "https://...",
      "vod_remarks": "更新至第24集",
      "vod_year": "2024",
      "vod_type": "动漫"
    }
  ]
}
```

### 2. 详情接口

**接口**: `/api?do=detail`

**参数**:
- `id`: 站点key
- `ids`: 视频ID

**示例**:
```
GET http://127.0.0.1:9978/api?do=detail&id=玩偶&ids=1
```

**返回格式**:
```json
{
  "list": [
    {
      "vod_id": "1",
      "vod_name": "仙逆",
      "vod_play_from": "线路1$$$线路2",
      "vod_play_url": "第1集$http://...#第2集$http://..."
    }
  ]
}
```

### 3. 播放地址解析

播放地址通常包含在 `vod_play_url` 字段中，格式为：
```
剧集名称$播放地址#剧集名称$播放地址
```

多个线路用 `$$$` 分隔：
```
线路1剧集列表$$$线路2剧集列表
```

## 实现方案

### 方案一：连接本地TVBox服务器

**优点**:
- 获取真实数据
- 地址可播放
- 功能完整

**缺点**:
- 需要启动TVBox应用
- 依赖本地环境

### 方案二：模拟Spider执行

**优点**:
- 不依赖TVBox应用
- 可独立运行

**缺点**:
- 实现复杂
- 需要Spider环境

### 方案三：使用公开API

**优点**:
- 不依赖本地环境
- 数据真实

**缺点**:
- 需要找到可用API
- 可能有访问限制

## 当前实现

当前使用的是**模拟数据**，地址格式正确但无法播放。

要获取真实可播放的地址，需要：
1. 启动TVBox应用（Android）
2. 连接本地服务器（http://127.0.0.1:9978）
3. 调用真实API接口

## 替代方案

由于TVBox需要Android环境，我们可以：

1. **使用测试数据**: 提供一些真实可用的测试地址
2. **集成第三方API**: 使用公开的视频API
3. **提供配置说明**: 说明如何连接真实TVBox服务器
