# 前端搜索播放地址问题分析

## 问题描述

前端搜索视频时，无法获取到真实的播放地址。

## 问题分析

### 1. 当前流程

```
前端
  ↓
1. 加载配置
  ├─ POST /api/config/load
  └─ URL: http://www.饭太硬.com/tv
  ↓
2. 搜索视频
  ├─ POST /api/search
  ├─ keyword: "仙逆"
  └─ 调用 SearchService.search()
  ↓
3. 获取播放信息
  ├─ POST /api/player/info
  ├─ siteKey, siteName, videoId, videoName
  └─ 调用 PlayerService.getPlayInfo()
  ↓
4. 返回播放地址
  └─ 可能是模拟数据
```

### 2. 数据获取优先级

**搜索服务 (SearchService)**:
1. Spider引擎执行（HTTP类型的Spider）
2. AppSx专用方法
3. TVBox服务器
4. 返回错误信息

**播放服务 (PlayerService)**:
1. TVBox服务器
2. Spider引擎（已加载的Spider）
3. 模拟数据

### 3. 问题根源

#### 问题1: Spider引擎未正确集成到播放服务

**当前状态**:
- 搜索服务：✅ 已集成Spider引擎
- 播放服务：⚠️ Spider管理器独立，未共享

**问题**:
- 搜索时加载的Spider实例
- 播放时无法访问
- 导致播放服务无法使用Spider引擎

#### 问题2: TVBox服务器未运行

**当前状态**:
- TVBox服务器地址：`http://127.0.0.1:9978`
- 默认不可用

**问题**:
- 播放服务优先尝试TVBox服务器
- 服务器不可用时失败
- 降级到模拟数据

#### 问题3: Spider缓存机制不完善

**当前状态**:
- Spider管理器独立
- 搜索和播放各自管理
- 无法共享Spider实例

**问题**:
- 搜索时加载的Spider
- 播放时需要重新加载
- 或者无法访问

## 解决方案

### 方案1: 共享Spider管理器（推荐）

**实现步骤**:
1. 创建全局Spider管理器
2. 搜索和播放服务共享同一个实例
3. 避免重复加载

**代码修改**:

```typescript
// 创建全局Spider管理器
// spider-manager.module.ts
import { Module, Global } from '@nestjs/common';
import { SpiderManager } from '@tvbox/spider-engine';

@Global()
@Module({
  providers: [
    {
      provide: 'SPIDER_MANAGER',
      useFactory: () => {
        return new SpiderManager({
          maxCacheSize: 20,
          cacheTime: 3600000,
          timeout: 30000,
          enableLog: true,
        });
      },
    },
  ],
  exports: ['SPIDER_MANAGER'],
})
export class SpiderManagerModule {}

// 修改搜索服务
constructor(
  private readonly configService: ConfigService,
  @Inject('SPIDER_MANAGER') private spiderManager: SpiderManager
) {}

// 修改播放服务
constructor(
  @Inject('SPIDER_MANAGER') private spiderManager: SpiderManager
) {}
```

### 方案2: 在播放服务中重新加载Spider

**实现步骤**:
1. 播放服务接收siteKey和api
2. 重新加载Spider
3. 调用detail方法

**代码修改**:

```typescript
async getPlayInfo(siteKey: string, siteName: string, videoId: string, videoName: string): Promise<PlayInfo> {
  // 1. 尝试从TVBox服务器获取
  const tvboxResult = await this.getPlayInfoFromTVBox(siteKey, videoId);
  if (tvboxResult) {
    return tvboxResult;
  }

  // 2. 尝试从Spider引擎获取
  const spider = await this.loadSpiderForSite(siteKey);
  if (spider) {
    const spiderResult = await this.getPlayInfoFromSpider(spider, siteKey, siteName, videoId);
    if (spiderResult) {
      return spiderResult;
    }
  }

  // 3. 返回模拟数据
  return this.getMockPlayInfo(siteKey, siteName, videoId, videoName);
}

private async loadSpiderForSite(siteKey: string): Promise<ISpider | null> {
  // 从配置中获取站点信息
  const site = this.configService.getConfig()?.sites?.find(s => s.key === siteKey);
  if (!site || !site.api || !site.api.startsWith('http')) {
    return null;
  }

  // 加载Spider
  return await this.spiderManager.loadSpider({
    key: site.key,
    api: site.api,
    ext: site.ext ? JSON.stringify(site.ext) : '',
  });
}
```
