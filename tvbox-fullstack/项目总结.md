# TVBox 全栈应用 - 项目总结

## 项目概述

已成功构建一个完整的全栈应用，使用 NestJS + SQLite 作为后端，Vue3 作为前端，实现了 TVBox 配置解析、视频搜索和播放地址获取功能。

## 实现成果

### 1. 后端服务 (NestJS)

#### ✅ 配置模块
- **ConfigService** - 配置解析服务
  - `loadConfig()` - 加载配置
  - `getConfig()` - 获取当前配置
  - `getSearchableSites()` - 获取支持搜索的站点
  - 支持配置解密（Base64、AES）
  - 支持JSON注释移除

- **ConfigController** - 配置API控制器
  - `POST /api/config/load` - 加载配置
  - `GET /api/config/current` - 获取当前配置
  - `GET /api/config/sites` - 获取所有站点
  - `GET /api/config/searchable-sites` - 获取可搜索站点

#### ✅ 搜索模块
- **SearchService** - 搜索聚合服务
  - `search()` - 多站点并发搜索
  - 支持并发控制
  - 支持超时设置
  - 结果聚合与统计

- **SearchController** - 搜索API控制器
  - `POST /api/search` - 搜索视频

#### ✅ 播放模块
- **PlayerService** - 播放地址解析服务
  - `getPlayInfo()` - 获取播放信息
  - `extractM3U8Urls()` - 提取M3U8地址
  - `extractAllUrls()` - 提取所有地址
  - 支持多线路解析
  - 支持M3U8/MP4识别

- **PlayerController** - 播放API控制器
  - `POST /api/player/info` - 获取播放信息
  - `POST /api/player/m3u8` - 提取M3U8地址

### 2. 前端应用 (Vue3 + Element Plus)

#### ✅ 主要功能
1. **配置加载界面**
   - 输入配置地址
   - 加载配置按钮
   - 加载状态提示

2. **视频搜索界面**
   - 搜索输入框
   - 搜索按钮
   - 搜索结果表格
   - 支持回车搜索

3. **播放地址界面**
   - 播放线路标签页
   - 剧集列表表格
   - 格式类型标签（M3U8/MP4）
   - 播放和复制按钮

#### ✅ 用户体验
- 响应式设计
- 加载状态提示
- 错误消息提示
- 操作成功提示
- 表格数据展示

## API 接口文档

### 配置接口

#### POST /api/config/load
加载配置文件

**请求：**
```json
{
  "url": "http://www.饭太硬.com/tv"
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "spider": "...",
    "sites": [...]
  }
}
```

### 搜索接口

#### POST /api/search
搜索视频

**请求：**
```json
{
  "keyword": "仙逆",
  "quickSearch": false,
  "timeout": 15000,
  "concurrency": 5
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "keyword": "仙逆",
    "totalSites": 36,
    "successSites": 5,
    "failedSites": 0,
    "totalVideos": 6,
    "results": [...],
    "duration": 1234
  }
}
```

### 播放接口

#### POST /api/player/info
获取播放信息

**请求：**
```json
{
  "siteKey": "玩偶",
  "siteName": "👽玩偶哥哥┃4K弹幕",
  "videoId": "1",
  "videoName": "仙逆"
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "siteKey": "玩偶",
    "siteName": "👽玩偶哥哥┃4K弹幕",
    "videoId": "1",
    "videoName": "仙逆",
    "sources": [
      {
        "name": "线路1-极速",
        "episodes": [
          {
            "name": "第1集",
            "url": "https://example.com/01.m3u8",
            "isM3U8": true,
            "isMP4": false
          }
        ]
      }
    ]
  }
}
```

## 使用流程

### 1. 启动应用

**方式一：使用启动脚本**
```bash
双击 start.bat
```

**方式二：手动启动**
```bash
# 安装后端依赖
cd backend
npm install

# 安装前端依赖
cd ../frontend
npm install

# 启动后端服务
cd ../backend
npm run start:dev

# 启动前端服务（新终端）
cd ../frontend
npm run dev
```

### 2. 访问应用

打开浏览器访问：`http://localhost:5173`

### 3. 使用步骤

1. **加载配置**
   - 输入配置地址（默认已填入）
   - 点击"加载配置"
   - 等待加载成功

2. **搜索视频**
   - 输入关键词（如：仙逆）
   - 点击"搜索"或按回车
   - 查看搜索结果

3. **获取播放地址**
   - 点击"获取播放地址"
   - 查看播放线路
   - 选择剧集
   - 点击"播放"或"复制"
