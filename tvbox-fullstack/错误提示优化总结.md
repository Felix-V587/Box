## 错误处理流程

### 搜索流程

```
搜索请求
   ↓
1. Spider引擎执行
   ├─ 成功 → 返回结果
   └─ 失败 → 记录错误，继续
   ↓
2. TVBox服务器
   ├─ 可用 → 返回结果
   └─ 不可用 → 记录错误，继续
   ↓
3. 返回错误信息
   - errorCode: SPIDER_NOT_SUPPORTED
   - error: "站点暂不支持或无法访问"
   - errorDetails: { siteKey, api, type }
```

## 调试功能

### 1. 详细日志输出

**Spider执行日志**:
```
[DEBUG] [SearchService] [站点名] 尝试Spider引擎执行
[DEBUG] [SearchService] [站点名] Spider类型: AppSx
[DEBUG] [SearchService] [站点名] AppSx API: http://...
✓ [SearchService] [站点名] Spider执行成功: 10个结果
```

**错误日志**:
```
[DEBUG] [SearchService] [站点名] Spider执行失败，尝试TVBox服务器
[DEBUG] [SearchService] [站点名] TVBox服务器不可用: 连接被拒绝
✗ [SearchService] [站点名] 执行失败: 站点暂不支持或无法访问
```

### 2. 错误分类

**网络错误**:
- DNS解析失败
- 连接被拒绝
- 请求超时
- HTTP错误状态

**Spider错误**:
- 不支持的Spider类型
- Spider执行失败
- API调用错误
- 数据解析错误

**配置错误**:
- 配置加载失败
- 配置解析失败
- 配置解密失败
- 缺少必要配置

### 3. 错误详情

每个错误都包含：
- **errorCode**: 错误代码（便于程序处理）
- **error**: 错误描述（便于用户理解）
- **errorDetails**: 错误详情（便于调试）

## 使用示例

### 查看错误信息

```typescript
const result = await searchService.search('仙逆');

result.results.forEach(site => {
  if (site.error) {
    console.log(`站点: ${site.siteName}`);
    console.log(`错误: ${site.error}`);
    console.log(`代码: ${site.errorCode}`);
    console.log(`详情:`, site.errorDetails);
  }
});
```

### 错误处理

```typescript
if (result.errorCode === ErrorCode.SPIDER_NOT_SUPPORTED) {
  console.log('该站点暂不支持，请选择其他站点');
} else if (result.errorCode === ErrorCode.NETWORK_ERROR) {
  console.log('网络错误，请检查网络连接');
} else if (result.errorCode === ErrorCode.TVBOX_SERVER_UNAVAILABLE) {
  console.log('TVBox服务器不可用，请启动TVBox应用');
}
```
