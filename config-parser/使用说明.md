# TVBox 配置解析器使用说明

## 项目概述

这是一个使用 Node.js + TypeScript 实现的 TVBox 配置解析器，成功复刻了原 Android 项目中的配置解析功能。

## 项目结构

```
config-parser/
├── src/
│   ├── index.ts      # 主入口文件
│   ├── parser.ts     # 配置解析器核心逻辑
│   ├── aes.ts        # AES加解密工具类
│   └── types.ts      # TypeScript类型定义
├── output/           # 解析结果输出目录
│   ├── config.json              # 解析后的完整配置
│   ├── decrypted-content.json   # 解密后的原始内容
│   ├── decrypted-raw.txt        # 解密后的原始文本（调试用）
│   └── clean-content.txt        # 清理后的内容（调试用）
├── package.json      # 项目配置
├── tsconfig.json     # TypeScript配置
└── README.md         # 项目说明
```

## 安装与运行

### 1. 安装依赖

```bash
cd config-parser
npm install
```

### 2. 运行解析器

```bash
npm start
```

## 功能特性

### ✅ 已实现功能

1. **配置加载**
   - 支持 HTTP/HTTPS 协议
   - 支持自定义 User-Agent
   - 支持超时设置和重试机制

2. **URL格式处理**
   - 支持 `clan://` 协议转换
   - 支持 `;pk;` 分隔符提取加密密钥
   - 自动添加协议前缀

3. **内容解密**
   - ✅ 普通JSON直接解析
   - ✅ Base64编码配置（`********`前缀）
   - ✅ AES-ECB加密（使用密钥）
   - ✅ AES-CBC加密（`2423`开头）

4. **JSON处理**
   - ✅ 移除单行注释（`//`）
   - ✅ 移除多行注释（`/* */`）
   - ✅ 移除尾随逗号
   - ✅ 智能识别字符串内的注释符号

5. **结果输出**
   - 控制台格式化输出
   - JSON文件保存
   - 调试信息保存

## 解析流程

```
1. 获取配置URL
   ↓
2. 处理特殊格式
   - clan:// → 转换为HTTP地址
   - ;pk; → 提取解密密钥
   ↓
3. 网络请求获取配置内容
   - 支持重试机制（默认3次）
   - 超时时间：60秒
   ↓
4. 内容解密处理
   - 检测是否为JSON
   - Base64解码
   - AES-CBC解密
   - AES-ECB解密
   ↓
5. JSON清理
   - 移除注释
   - 移除尾随逗号
   ↓
6. JSON解析
   ↓
7. 输出结果
   - 控制台显示
   - 文件保存
```

## 核心类说明

### ConfigParser

配置解析器主类，负责整个解析流程。

**主要方法：**
- `loadConfig(apiUrl: string, retries: number)` - 加载配置
- `processUrl(apiUrl: string)` - 处理URL特殊格式
- `clanToAddress(lanLink: string)` - Clan协议转换
- `findResult(json: string, configKey: string)` - 内容解密
- `removeJsonComments(content: string)` - 移除JSON注释

### AES

AES加解密工具类，提供ECB和CBC模式解密。

**主要方法：**
- `ECB(data: string, key: string)` - ECB模式解密
- `CBC(data: string, key: string, iv: string)` - CBC模式解密
- `rightPadding(str: string, padChar: string, length: number)` - 右填充
- `isJson(str: string)` - 检查是否为JSON

## 技术栈

- **Node.js** - 运行环境
- **TypeScript** - 开发语言
- **Axios** - HTTP请求库
- **Crypto** - Node.js内置加密模块

## 与原Android项目对比

### 相同点
1. 解析流程完全一致
2. 支持相同的配置格式
3. 解密算法相同
4. 输出结果结构相同

### 不同点
1. 使用TypeScript实现，类型更安全
2. 使用Node.js内置crypto模块，无需额外依赖
3. 添加了重试机制和更详细的错误处理
4. 输出结果更友好，支持格式化显示

## 扩展性

项目设计具有良好的扩展性，可以轻松添加：

2. **新的协议支持** - 在processUrl方法中添加处理逻辑

4. **配置验证** - 添加验证逻辑确保配置正确性

## 注意事项

1. 网络请求可能因网络问题失败，已添加重试机制
2. 某些配置可能使用特殊加密，需要提供密钥
3. JSON中的注释会被自动移除
4. 控制字符会被自动处理
