# 播放地址获取功能实现总结

## 项目概述

已成功实现视频播放地址获取功能，可以根据搜索结果获取视频详情并解析出M3U8等播放地址。

## 实现成果

### 1. 核心功能模块

#### ✅ PlayerParser（播放地址解析器）
- 获取视频详情
- 解析播放线路
- 解析剧集列表
- 提取M3U8地址
- 提取所有播放地址

#### ✅ 播放地址解析
- 支持多线路解析（用`$$$`分隔）
- 支持多剧集解析（用`#`分隔）
- 支持剧集名称和地址解析（用`$`分隔）
- 自动识别M3U8和MP4格式

### 3. 类型定义

```typescript
// 播放线路
interface PlaySource {
  name: string;           // 线路名称
  episodes: Episode[];    // 剧集列表
}

// 剧集
interface Episode {
  name: string;           // 剧集名称
  url: string;            // 播放地址
  isM3U8?: boolean;       // 是否为M3U8
  isMP4?: boolean;        // 是否为MP4
}

// 播放信息
interface PlayInfo {
  siteKey: string;
  siteName: string;
  videoId: string;
  videoName: string;
  sources: PlaySource[];  // 所有播放线路
  currentSource?: PlaySource;
  currentEpisode?: Episode;
}
```

## 播放地址获取流程

### 完整流程

```
1. 从搜索结果选择视频
   - 站点Key
   - 视频ID
   - 视频名称
   ↓
2. 获取视频详情
   - API: /api?do=detail&id={站点key}&ids={视频ID}
   - 返回视频详细信息
   ↓
3. 解析播放地址
   - vod_play_from: 播放线路（用$$$分隔）
   - vod_play_url: 播放地址（用$$$分隔线路，用#分隔剧集）
   ↓
4. 解析剧集列表
   - 用#分隔不同剧集
   - 用$分隔剧集名称和地址
   ↓
5. 识别播放格式
   - M3U8: 地址包含.m3u8
   - MP4: 地址包含.mp4
   ↓
6. 输出播放信息
   - 控制台显示
   - JSON文件保存
```

### 播放地址格式示例

**原始数据：**
```
vod_play_from: "线路1$$$线路2"
vod_play_url: "第1集$http://xxx.m3u8#第2集$http://yyy.m3u8$$$第1集$http://aaa.mp4#第2集$http://bbb.mp4"
```

## 技术实现细节

### 1. 视频详情获取

```typescript
async getVideoDetail(siteKey: string, videoId: string): Promise<VideoDetail | null> {
  const detailUrl = `${this.baseUrl}/api?do=detail&id=${siteKey}&ids=${videoId}`;
  const response = await axios.get(detailUrl, { timeout: 30000 });
  return response.data.list[0];
}
```

### 2. 播放地址解析

```typescript
parsePlayUrl(vodPlayFrom: string, vodPlayUrl: string): PlaySource[] {
  // 分割播放来源（多个线路用$$$分隔）
  const playFroms = vodPlayFrom.split('$$$');
  const playUrls = vodPlayUrl.split('$$$');

  // 解析每个线路的剧集列表
  for (let i = 0; i < playFroms.length; i++) {
    const episodes = this.parseEpisodes(playUrls[i]);
    sources.push({ name: playFroms[i], episodes });
  }

  return sources;
}
```

### 3. 剧集列表解析

```typescript
private parseEpisodes(urlStr: string): Episode[] {
  // 用#分隔不同剧集
  const items = urlStr.split('#');

  for (const item of items) {
    // 用$分隔剧集名称和地址
    const parts = item.split('$');
    episodes.push({
      name: parts[0],
      url: parts[1],
      isM3U8: parts[1].includes('.m3u8'),
      isMP4: parts[1].includes('.mp4')
    });
  }

  return episodes;
}
```

### 4. M3U8地址提取

```typescript
extractM3U8Urls(playInfo: PlayInfo): Episode[] {
  const m3u8Episodes: Episode[] = [];

  for (const source of playInfo.sources) {
    for (const episode of source.episodes) {
      if (episode.isM3U8) {
        m3u8Episodes.push(episode);
      }
    }
  }

  return m3u8Episodes;
}
```
