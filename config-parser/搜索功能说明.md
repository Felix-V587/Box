# 搜索聚合功能说明

## 功能概述

已实现搜索聚合功能，可以同时在多个站点源搜索视频内容。

## 实现的功能

### 1. 搜索聚合器 (SearchAggregator)
- ✅ 支持多站点并发搜索
- ✅ 支持指定站点搜索
- ✅ 支持快速搜索和普通搜索
- ✅ 支持并发数控制
- ✅ 支持超时设置
- ✅ 自动统计搜索结果

### 2. 结果处理
- ✅ 结果聚合与排序
- ✅ 按站点分组显示
- ✅ 失败站点统计
- ✅ 结果持久化保存

### 3. 输出格式
- ✅ 控制台格式化输出
- ✅ JSON文件保存
- ✅ 简化列表导出

## 使用方法

### 前提条件

**重要：** 搜索功能需要本地 TVBox 服务器支持！

TVBox 应用会在本地启动一个服务器（默认端口 9978），提供 API 接口：
- 搜索接口：`http://127.0.0.1:9978/api?do=search&id={站点key}&wd={关键词}`

### 运行搜索

```bash
cd config-parser
npm run search
```

### 搜索参数

在 `src/search-index.ts` 中可以配置：

```typescript
const result = await aggregator.search({
  keyword: '仙逆',           // 搜索关键词
  quickSearch: false,        // 是否快速搜索
  timeout: 15000,            // 超时时间（毫秒）
  concurrency: 5             // 并发数
});
```

## 输出文件

搜索完成后会在 `output` 目录生成：

1. **search-result.json** - 完整的搜索结果（包含所有详细信息）
2. **search-list.json** - 简化的结果列表（便于处理）

## 技术实现

### 核心类

#### SearchAggregator
搜索聚合器主类，负责协调多个站点的搜索。

**主要方法：**
- `search(options)` - 执行搜索
- `searchSite(site, keyword)` - 搜索单个站点
- `getSearchableSites()` - 获取支持搜索的站点列表

### 搜索流程

```
1. 加载配置文件
   ↓
2. 筛选支持搜索的站点
   ↓
3. 分批并发搜索
   - 构建搜索URL
   - 发送HTTP请求
   - 解析搜索结果
   ↓
4. 聚合所有结果
   ↓
5. 统计与排序
   ↓
6. 输出与保存
```

## 注意事项

### 1. 本地服务器依赖

搜索功能依赖本地 TVBox 服务器，如果服务器未启动，所有搜索请求都会失败。

**解决方案：**
- 启动 TVBox Android 应用
- 或实现一个模拟服务器（后续可添加）

### 2. 网络超时

部分站点可能响应较慢，已设置默认超时时间为15秒。

### 3. 并发控制

为避免对服务器造成过大压力，默认并发数为5。

### 4. 结果差异

不同站点返回的数据格式可能略有差异，已做兼容处理。
